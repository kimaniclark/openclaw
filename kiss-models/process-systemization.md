# Kiss Models — Process Systemization

## Goal
Systemize all modeling agency processes so Tron can handle them automatically with minimal input from Victoria. Once documented, these processes form the **Agency Playbook** — potentially sellable to other agencies.

## Process Creation Framework

### Step 1: Identify
- Watch for tasks Victoria does repeatedly
- When she asks for something new, consider: can this be a repeatable process?
- Ask Victoria if she'd like to turn it into an automated process

### Step 2: Define
- Ask questions until the process is fully understood
- Get it down to an acceptable template with clear rules

### Step 3: Test
- Run a test with the template
- Have Victoria review the output

### Step 4: Approve & Store
- Get final example approved
- Save the rules + approved example as a reference document
- Victoria/Kimani review the markdown to confirm

### Step 5: Automate
- Use the stored rules to handle future instances automatically
- Escalate only when something falls outside the defined rules
