# Casting Template — Kiss Models

## Format

```
[Type] Photoshoot

Client: [Client Name]

Location: [City, State]
Date: [Date]
Duration: Up to [X] hours

[Details / model specs / look description]

Usage: [Usage terms]

Rate: $[Amount]
```

## Notes
- Rate shown to models is AFTER Kiss Models' 20% commission is deducted
- Example: Client pays $1,000 → Model rate = $800
- Always use this format for consistency
