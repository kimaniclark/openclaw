## Development Workflow (Replicable)

This is the exact process Johnny used to create this dashboard:

### Phase 1: Data Extraction (2 hours)
1. Get API access to client's Asana workspace
2. Extract all tasks from relevant projects:
   - House Logistics
   - Weekly Ongoing
   - Quarterly Maintenance
3. Download all attachments (photos, videos)
4. Deduplicate recurring tasks
5. Save to JSON for processing

### Phase 2: Organization (1 hour)
1. Categorize tasks by frequency (weekly, quarterly, as-needed)
2. Group by room/area (kitchen, bedroom, deck, etc.)
3. Identify tasks with video/photo attachments
4. Create logical structure for navigation

### Phase 3: Dashboard Creation (3 hours)
1. Build HTML template with clean design
2. Add collapsible task functionality (click to expand)
3. Integrate photos and videos
4. Convert MOV videos to MP4 (browser compatibility)
5. Add search functionality
6. Test on mobile devices
7. Polish design (Apple-inspired aesthetic)

### Phase 4: Delivery (30 min)
1. Create backup copy
2. Test all videos play correctly
3. Package HTML + attachments folder
4. Deliver to client
5. Brief walkthrough call

**Total Time**: ~6.5 hours from start to sellable product

## Lessons Learned

### What Worked
- **Asana API extraction** - Fast, complete data
- **Collapsible UI** - Clean, scannable interface
- **MP4 video conversion** - Browser compatibility essential
- **Real data** - Using actual client system made it authentic
- **Click-to-enlarge photos** - Better than inline full-size
- **Category organization** - Easier navigation than flat list

### What to Improve for Next Client
- **Auto-generate from template** - Script the HTML creation
- **Client photo/video upload flow** - Make it easy for them to add media
- **Print-friendly version** - Some assistants prefer paper
- **Multi-language support** - Many assistants speak other languages
- **Task completion tracking** - Optional checklist integration
- **Calendar integration** - Link weekly tasks to specific days

### Technical Learnings
- **MOV videos don't work in browsers** - Always convert to MP4
- **ffmpeg is essential** - Install it early in the process
- **Relative paths** - Keep everything portable
- **Keep it simple** - Single HTML file beats complex frameworks
- **Mobile-first** - Assistants often use phones, not computers
