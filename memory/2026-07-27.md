### Portfolio Pad Navigation Lessons Learned
- **Login:** victoria@kissmodelmanagement.com / credentials in credentials.json
- **Calendar events:** DevExpress scheduler — clicking events requires Playwright native click on `#ctl00_rootContent_schCalendar_aptsBlock_AptDiv0`, NOT JavaScript dispatched events
- **Tooltip with talent list:** Appears after clicking event; dropdown shows assigned talent with dates
- **Package creation flow:** packages-create.aspx → enter package name → enter role name → check model checkboxes → click "add" → models get added to role → click "edit" tab → package is saved
- **Checkboxes:** Use JavaScript `document.querySelectorAll('input[type="checkbox"]')` and walk text nodes to find model names near checkboxes
- **Castings section** (castings.aspx) showed "No data" — castings Victoria sends are availability checks, not incoming castings
- **Packages section** (packages.aspx) lists outgoing packages with status/open rates
