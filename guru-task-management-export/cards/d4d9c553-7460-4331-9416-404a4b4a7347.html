This is how to view all tasks with a particular label in Motion:To view all tasks with a specific label on both the mobile app and desktop app, you can follow these steps:1. Go to the ‘Projects & Tasks’ tab.
2. Select the task you want to label.
3. Click on ‘Label’ > ‘+ Add Label’ > ‘+ Add new label’ (if you’re creating a new label) or check the checkbox corresponding to the label (if you’re using an existing label).
4. Navigate to ‘Workspaces’ > ‘Kanban’ and apply the filters: ‘Group by: Label’ and ‘Type: Tasks’ to view your tasks organized by labels.This way, you’ll be able to see all tasks
