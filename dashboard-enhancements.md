## Fitness Section

### Previous Week Performance Display
**Goal:** Show last week's completed activities for comparison

**Visual concept:**
```
This Week (Feb 3-9):        Last Week (Jan 27-Feb 2):
💪 Working Out: ○ ○ (0/2)    ✓ ✓ (2/2) 🔥
🥋 Jiu Jitsu:   ○ ○ (0/2)    ✓ ○ (1/2)
🏃 Running:     ○ ○ (0/2)    ✓ ✓ (2/2) 🔥
```

**Benefits:**
- See weekly progress/regression at a glance
- Motivational ("Hit it 2/2 last week, do it again!")
- Identify patterns (always skip running?)
- Streak tracking potential

**Implementation notes:**
- Store weekly completion data in JSON file
- Display side-by-side or below current week
- Add streak counter for consecutive weeks hitting all goals
- Maybe monthly view showing all 4 weeks
